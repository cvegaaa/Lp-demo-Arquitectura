# Landing de Estudio de Arquitectura

Landing page demo para un estudio de arquitectura.

## Qué resuelve

Presenta el portafolio de proyectos y servicios de un estudio de arquitectura, con formulario de contacto para solicitar una propuesta.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS
